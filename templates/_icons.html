{# _icons.html - the app's icon set (UI refresh, 2.1.0). USAGE, in any template: {% from "_icons.html" import icon %} {{ icon("calendar") }} decorative: hidden from screen readers {{ icon("trash-2", label="Eliminar") }} meaningful on its own: read aloud WHY: until 2.1.0 the interface used 18 different emoji as icons (in the navbar, on buttons, in card details). Emoji are full-colour cartoons that every phone and computer draws differently, so they never matched the walnut/burgundy palette and looked different on every device. These are thin line icons drawn with `currentColor`, so each one simply takes the colour of the text around it and looks the same everywhere. The MEAT emoji (config.py's ICONOS_TIPO_CARNE) are deliberately not replaced: they're content, not interface chrome. WHERE THEY COME FROM: Lucide (https://lucide.dev), lucide-static v0.460.0, copied in as plain SVG - no library, no CDN, no JavaScript. Only the drawing elements were copied (a script kept path/rect/circle/ line elements with geometry attributes and nothing else). To add an icon: take its SVG from the same Lucide version and add its shapes to the icon() macro below as one more branch, under its Lucide name.
